Seus dados

Tudo fica guardado neste aparelho, neste navegador. Baixe um backup de vez em quando. É também assim que você leva os dados para outro aparelho.

Leitura de foto no app

Opcional. Com uma chave de API da Anthropic, o botão "Ler foto do cupom" lê a foto direto aqui. O uso é cobrado na sua conta de API, que é separada da assinatura do Claude. Sem chave, use "Colar leitura do Claude".

A chave fica guardada só neste navegador e vai direto para a Anthropic. Use uma chave exclusiva para este app, com limite de gasto, e não a salve em aparelho de outras pessoas.

Usar no celular

  1. Coloque este arquivo em um endereço da internet. Um serviço gratuito de hospedagem de páginas serve, como Netlify Drop ou GitHub Pages.
  2. Abra o endereço no Chrome do celular.
  3. No menu ⋮, escolha "Adicionar à tela inicial".

Abrir o arquivo direto do celular serve para testar, mas alguns navegadores não guardam os dados nesse modo. Cada endereço e cada navegador têm dados próprios. Use o backup para passar de um para outro.
